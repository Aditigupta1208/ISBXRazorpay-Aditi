# 8. Agent setup

- **Agent card** with a real on/off switch.
- **"Where this fits" strip:** you brief it, it checks each dispute, you decide.
- **Your terms:** policy and acceptance wording, saved as you type and sent to the model as your claim, never as proof.
- **"It will" and "What it will never do" cards,** the five reasons covered, and a link to Alerts.
- **Sticky live preview** of what the advisor is told, and "Try it on C13".
- **Terms safety:** terms with a card number or over 1,000 characters are not sent with any check; the live preview says so, and a check run with such terms says it ran without them. A damaged saved setup falls back field by field.
- **Reset the demo** keeps your Agent setup and now also clears alert rules and the ratio numbers.
